# Glitched portrait artwork

The 30 WebP portraits in this directory represent the existing Crittercards animal roster. The filenames match animal IDs and no game characters originate from these files.

Source: four atlases produced with the built-in ImageGen tool for this project on November 28, 2026. The second pass used the Crittercards badger and magpie portraits as painting references while preserving the mechanical subjects and atlas order. The source images were sliced along their cell boundaries and exported as 384 × 384 WebP files. Godot uses 160 × 160 copies prepared by its setup script.

The generation prompts called for a three-by-three portrait atlas with machined cyan and magenta armor plates, dark gunmetal joints, glowing printed circuit traces and electronic eyes. Each portrait used a moonlit pine forest backdrop with textured matte brushwork, worn metal, independent framing and a recognizable species silhouette. The four subject sets followed the existing roster order, with unused alternate portraits on the last atlas excluded from the game files.
